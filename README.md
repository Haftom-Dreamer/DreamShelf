# ✦ DreamShelf

A celestial personal universe for curating, tracking, and reviewing your favorite movies and books. Built with Python and Flask.

## ✨ Features

- **Celestial Dual Library** — Track movies and books in one cohesive shelf
- **Google Sign-In & Sign-Up** — Instant authorization with Google OAuth 2.0 or traditional email/password
- **Personal Ratings & Reviews** — Score titles, write private reviews, and record watched/read dates
- **Cosmic Discovery** — Personalized recommendations from TMDB and Google Books APIs
- **Visual Analytics** — Reading/watching streaks, monthly milestones, and genre charts
- **Social Feed & Profiles** — Follow friends and explore public collections
- **CSV Import** — Easily import movie watchlists
- **Ethereal Dream Theme** — Custom dark-mode UI with fluid animations and responsive layout

## 🚀 Tech Stack

- **Backend**: Python 3.12, Flask, Flask-Login, Flask-SQLAlchemy, Flask-WTF
- **Database**: SQLite
- **APIs**: The Movie Database (TMDB) API, Google Books API, Google OAuth 2.0
- **Frontend**: HTML5, CSS3, Jinja2, FontAwesome, JavaScript
